# 🔐 Digital Evidence Verification and Chain of Custody Management

## 📌 Project Overview

The **Digital Evidence Verification and Chain of Custody Management System** is a digital forensics project designed to maintain the integrity, authenticity, and traceability of digital evidence.

The system helps investigators securely manage digital evidence, verify file integrity using cryptographic hashing, and maintain a chronological record of evidence handling activities.

## 🎯 Objectives

- Ensure the integrity and authenticity of digital evidence.
- Detect unauthorized modifications to evidence files.
- Maintain a complete chain of custody.
- Record evidence collection and transfer details.
- Improve transparency and accountability in digital investigations.

## ✨ Key Features

- **Evidence Upload:** Upload and manage digital evidence files.
- **Hash Generation:** Generate SHA-256 hash values for evidence.
- **Evidence Verification:** Verify whether evidence has been modified.
- **Chain of Custody:** Maintain records of evidence handling and transfers.
- **Timestamp Recording:** Record important evidence activities.
- **Evidence Tracking:** Track evidence throughout its lifecycle.
- **Secure Management:** Organize evidence records systematically.

## 🛠️ Technologies Used

## ⚙️ System Workflow

1. Investigator uploads a digital evidence file.
2. The system generates a unique SHA-256 hash.
3. Evidence details are stored in the database.
4. Every evidence handling activity is recorded.
5. The system verifies evidence using hash comparison.
6. Verification results are displayed to the investigator.
